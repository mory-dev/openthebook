# OpenTheBook distribution kit

## One-line description

OpenTheBook is a free, lightweight desktop reader for PDF, EPUB, AZW3, and MOBI files.

## Short description

Just open a book. OpenTheBook is a simple, local-first ebook reader for Windows and Linux with no library, account, ads, or clutter.

## Feature bullets

- Open PDF, EPUB, AZW3, and MOBI files
- Double-click files after installation
- Lightweight and fast to launch
- Books stay on your computer
- Automatic signed updates after reading sessions
- Free software with no subscription
